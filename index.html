ENGINEERING PILOT

What this page can establish

It calculates agreement with reference measurements you enter and summarizes technical recording checks. It does not establish clinical validity, diagnose a condition, or automatically verify that a reference instrument is accurate.

1 · Paired angle measurements

For each trial, enter the NeuroTrack estimated peak excursion and a reference angle measured using a consistent protocol (for example, a goniometer). Use the same movement, participant code, placement and assessor where possible.

No paired measurements saved yet.

2 · Signal quality gate

Each completed session is checked for sample completeness, numeric validity and obvious sensor-range clipping. These are preliminary engineering rules; they are not validated clinical thresholds.

Good recordingAt least 95% of expected samples and no detected numeric/clipping issue.
Review recording80–94.9% of expected samples, or a technical warning requiring review.
Invalid / incompleteBelow 80% of expected samples, too few samples, or no usable sensor data.

The current expectation is 20 seconds at approximately 100 samples/second. Confirm this matches your firmware before treating completeness as meaningful. Quality labels only flag technical concerns.

3 · Keep your project usable long-term

Saved sessions and profiles currently live in this browser only. Hosting the site on a new domain creates a separate browser storage area. Export a backup before changing browsers, devices, folders or hosting addresses.

The JSON backup includes participant profiles, saved session summaries and validation entries. Raw sample arrays are not retained after a page reload; download each session's raw CSV while it is available. Keep backups private and use anonymous participant codes only.
